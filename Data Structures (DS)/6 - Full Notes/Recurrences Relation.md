### **What is a Recurrence Relation?**

Definition:

A Recurrence Relation is a mathematical equation where the current value depends on the values of previous steps. It is used to find the Time Complexity of recursive algorithms (like Merge Sort, Quick Sort, or Fibonacci).

The Logic:

Instead of calculating the whole problem at once, we define the problem in terms of a smaller version of itself.

**Example (Fibonacci Sequence):**

- To get the number 5, you add the previous two numbers (2 and 3).
    
- **Formula:** $F(n) = F(n-1) + F(n-2)$
    
- This equation is a Recurrence Relation.

### **1. Master Theorem (The "Formula" Method)**

This is the fastest method but only works for relations in the form:

$$T(n) = aT\left(\frac{n}{b}\right) + f(n)$$

Where $a \ge 1$ (subproblems) and $b > 1$ (dividing factor).

The Formula (Three Cases):

First, calculate the "Critical Value": $C = n^{\log_b a}$

Compare $C$ with the work done outside ($f(n)$).

1. **Case 1 (Tree Heavy):** If $C > f(n)$, then $T(n) = O(C)$.
    
2. **Case 2 (Balanced):** If $C = f(n)$, then $T(n) = O(C \cdot \log n)$.
    
3. **Case 3 (Root Heavy):** If $C < f(n)$, then $T(n) = O(f(n))$.
    

#### **Example 1: Binary Search**

- **Relation:** $T(n) = 1T(n/2) + 1$
    
- **Identify:** $a = 1$, $b = 2$, $f(n) = 1$ (which is $n^0$).
    
- **Calculate C:** $C = n^{\log_2 1} = n^0 = 1$.
    
- **Compare:** $C$ (1) is **equal** to $f(n)$ (1).
    
- **Result (Case 2):**
    
    $$T(n) = O(1 \cdot \log n) = O(\log n)$$
    

#### **Example 2: Matrix Multiplication (Strassen's)**

- **Relation:** $T(n) = 7T(n/2) + n^2$
    
- **Identify:** $a = 7$, $b = 2$, $f(n) = n^2$.
    
- **Calculate C:** $C = n^{\log_2 7} \approx n^{2.81}$.
    
- **Compare:** $C$ ($n^{2.81}$) is **greater than** $f(n)$ ($n^2$).
    
- **Result (Case 1):**
    
    $$T(n) = O(n^{\log_2 7}) \approx O(n^{2.81})$$

### **2. Iteration Method (Back Substitution)**

**The Concept:** Keep expanding the terms ($n \to n-1 \to n-2$) until you find a pattern (series), then sum the series.

**The Formula:**

$$T(n) = \text{Sum of the series generated by expansion}$$

#### **Example 1: Factorial / Linear Search**

- **Relation:** $T(n) = T(n-1) + 1$ (Base case $T(0) = 0$)
    
- **Step 1:** Expand
    
    - $T(n) = [T(n-2) + 1] + 1 \Rightarrow T(n-2) + 2$
        
    - $T(n) = [T(n-3) + 1] + 2 \Rightarrow T(n-3) + 3$
        
- **Step 2:** Find Pattern for $k$ steps
    
    - $T(n) = T(n-k) + k$
        
- **Step 3:** Reach Base Case ($n-k = 0 \Rightarrow k = n$)
    
    - $T(n) = T(0) + n$
        
    - $T(n) = 0 + n$
        
- **Result:** $O(n)$
    

#### **Example 2: Binary Search (Alternative)**

- **Relation:** $T(n) = T(n/2) + 1$
    
- **Step 1:** Expand
    
    - $T(n) = [T(n/4) + 1] + 1 \Rightarrow T(n/2^2) + 2$
        
    - $T(n) = [T(n/8) + 1] + 2 \Rightarrow T(n/2^3) + 3$
        
- **Step 2:** Pattern for $k$ steps
    
    - $T(n) = T(n/2^k) + k$
        
- **Step 3:** Reach Base Case ($n/2^k = 1 \Rightarrow n = 2^k \Rightarrow k = \log_2 n$)
    
    - $T(n) = T(1) + \log_2 n$
        
- **Result:** $O(\log n)$

### **3. Recursion Tree Method**

**The Concept:** Draw a tree where each node represents the cost. Sum the cost of each level, then sum the total levels.

**The Formula:**

$$Total = \sum (\text{Cost of Level } 0) + (\text{Cost of Level } 1) + \dots + (\text{Cost of Last Level})$$

#### **Example 1: Merge Sort**

- **Relation:** $T(n) = 2T(n/2) + n$
    
- **Level 0:** Cost is $n$.
    
- **Level 1:** Divides into 2 nodes of size $n/2$. Total cost: $2 \times (n/2) = n$.
    
- **Level 2:** Divides into 4 nodes of size $n/4$. Total cost: $4 \times (n/4) = n$.
    
- **Tree Height:** Since we divide by 2, height is $\log_2 n$.
    
- **Total Sum:** We have $\log n$ levels, and each level costs $n$.
    
- **Result:** $n \times \log n = O(n \log n)$
    

#### **Example 2: Weird Split**

- **Relation:** $T(n) = 2T(n/2) + n^2$
    
- **Level 0:** Cost is $n^2$.
    
- **Level 1:** 2 subproblems of size $n/2$. Cost: $2 \times (n/2)^2 = 2 \times (n^2/4) = n^2/2$.
    
- **Level 2:** 4 subproblems of size $n/4$. Cost: $4 \times (n/4)^2 = 4 \times (n^2/16) = n^2/4$.
    
- **Series:** $n^2 + n^2/2 + n^2/4 + \dots$ (Geometric Series).
    
- **Sum:** In a decreasing geometric series, the sum is dominated by the first term (the largest term).
    
- **Result:** $O(n^2)$

### **4. Substitution Method (Proof Method)**

**The Concept:** You **guess** the answer first, then prove it using Mathematical Induction.

**The Logic:**

1. **Guess:** $T(n) = O(g(n))$
    
2. **Inductive Hypothesis:** Assume $T(k) \le c \cdot g(k)$ for all $k < n$.
    
3. **Prove:** Show that $T(n) \le c \cdot g(n)$ holds true.
    

#### **Example 1: Guessing Linear Time**

- **Relation:** $T(n) = 2T(n/2) + n$
    
- **Guess:** We think it is $O(n)$ (This is a **wrong** guess, let's see why).
    
- **Assume:** $T(k) \le c \cdot k$. Therefore, $T(n/2) \le c \cdot (n/2)$.
    
- **Substitute:**
    
    - $T(n) = 2 \cdot [c \cdot (n/2)] + n$
        
    - $T(n) = c \cdot n + n$
        
    - $T(n) = (c+1)n$
        
- **Check:** Is $(c+1)n \le cn$? **No.** It's impossible for $(c+1)$ to be smaller than $c$.
    
- **Result:** Proof Failed. Our guess $O(n)$ was wrong. (Correct is $n \log n$).
    

#### **Example 2: Guessing O(n) correctly**

- **Relation:** $T(n) = T(n/2) + T(n/2) + 1$ (which is $2T(n/2) + 1$).
    
- **Guess:** $O(n)$.
    
- **Assume:** $T(n/2) \le c \cdot (n/2) - b$ (We add a lower order term to help the math).
    
- **Substitute:**
    
    - $T(n) = 2[c(n/2) - b] + 1$
        
    - $T(n) = cn - 2b + 1$
        
- **Check:** We need $cn - 2b + 1 \le cn$.
    
    - $-2b + 1 \le 0 \Rightarrow 2b \ge 1 \Rightarrow b \ge 1/2$.
        
- **Result:** True. The complexity is $O(n)$.
