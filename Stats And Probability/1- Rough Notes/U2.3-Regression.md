## Concept of Regression and Its Importance

**Regression analysis** is a powerful statistical technique used to estimate the relationship between two or more variables. Its main objective is exactly what you stated: to understand how the value of a **dependent variable** (the outcome we want to predict, often denoted as $Y$) changes when one or more **independent variables** (the factors causing the change, often denoted as $X$) are varied.

The relationship is expressed through a **regression equation** that defines a line or curve, known as the **line of regression** or **best-fit line** .

### Importance

1.  **Explanation of Variation:** Regression quantifies the contribution of the independent variable(s) to the variation observed in the dependent variable. For example, it tells you what percentage of the change in crop yield ($Y$) is explained by the amount of fertilizer used ($X$).
2.  **Prediction and Forecasting:** Once the equation is established, it provides a mathematical framework for **predicting** the value of the dependent variable for any given value of the independent variable.

### Line of Regression of X on Y

In the context of regression, there are generally two lines, depending on the role assigned to the variables:

* **Regression of $Y$ on $X$ ($\hat{y}$ on $x$):** Used to predict the value of $Y$ (dependent) for a given value of $X$ (independent). This is the most common use.
* **Regression of $X$ on $Y$ ($\hat{x}$ on $y$):** Used to predict the value of $X$ (dependent) for a given value of $Y$ (independent). This is necessary when we reverse the predictive goal.

The **Line of Regression of $X$ on $Y$** is the line that minimizes the sum of squared horizontal deviations (errors) from the actual data points.

## Difference Between Correlation and Regression

| Feature | Correlation | Regression |
| :---: | :---: | :---: |
| **Objective** | Measures the **strength** and **direction** of the linear association between two variables. | Measures how the **mean value** of the dependent variable changes with the independent variable; used for **prediction**. |
| **Causation** | Does not imply causation; treats $X$ and $Y$ symmetrically. | Implies a cause-and-effect relationship (functional dependence); $Y$ depends on $X$. |
| **Units** | Unit-free (a pure number between $-1$ and $+1$). | Expressed in the **units** of the dependent variable ($Y$). |
| **Equation** | Has no predictive equation. | Defines the best-fit line (the regression equation). |

## Regression Lines & Equations

The regression equation is defined by the **regression coefficients** (the slope). We use the **Least Squares Method** (the same principle used in curve fitting) to derive these equations.

### General Form of Regression Equations (Straight Line)

1.  **Regression Line of $Y$ on $X$ (Predicting $Y$):**
    $$\hat{y} = a + b_{yx}x$$
    Where $\hat{y}$ is the predicted value of $Y$, $a$ is the intercept, and $\mathbf{b_{yx}}$ is the regression coefficient of $Y$ on $X$ (the slope).

2.  **Regression Line of $X$ on $Y$ (Predicting $X$):**
    $$\hat{x} = c + b_{xy}y$$
    Where $\hat{x}$ is the predicted value of $X$, $c$ is the intercept, and $\mathbf{b_{xy}}$ is the regression coefficient of $X$ on $Y$.

---

## Key Formulas & Step-by-Step Derivation

To satisfy the objective of prediction, we must calculate the coefficients ($b_{yx}$ and $b_{xy}$) and the intercepts ($a$ and $c$).

### 1. Regression Coefficients (Slopes)

The coefficients can be calculated using the following formulas (using the deviation form $\sum xy = \sum (X_i - \bar{X})(Y_i - \bar{Y})$):

* **Coefficient $b_{yx}$ (Slope of $\hat{y}$ on $x$):**
    $$b_{yx} = \frac{\sum xy}{\sum x^2}$$

* **Coefficient $b_{xy}$ (Slope of $\hat{x}$ on $y$):**
    $$b_{xy} = \frac{\sum xy}{\sum y^2}$$

### 2. Derivation of the Full Regression Equations

The derivation uses the principle that the regression line **must pass through the mean point $(\bar{X}, \bar{Y})$**.

#### A. Derivation of $\hat{y}$ on $x$

1.  Start with the general line equation: $\hat{y} = a + b_{yx}x$
2.  Since the line passes through $(\bar{X}, \bar{Y})$: $\bar{Y} = a + b_{yx}\bar{X}$
3.  Solve for the intercept $a$: $\mathbf{a = \bar{Y} - b_{yx}\bar{X}}$
4.  Substitute $a$ back into the original equation: $\hat{y} = (\bar{Y} - b_{yx}\bar{X}) + b_{yx}x$
5.  Rearrange to get the final form:
    $$\mathbf{(\hat{y} - \bar{Y}) = b_{yx}(x - \bar{X})}$$

#### B. Derivation of $\hat{x}$ on $y$

1.  Start with the general line equation: $\hat{x} = c + b_{xy}y$
2.  Since the line passes through $(\bar{X}, \bar{Y})$: $\bar{X} = c + b_{xy}\bar{Y}$
3.  Solve for the intercept $c$: $\mathbf{c = \bar{X} - b_{xy}\bar{Y}}$
4.  Substitute $c$ back into the original equation: $\hat{x} = (\bar{X} - b_{xy}\bar{Y}) + b_{xy}y$
5.  Rearrange to get the final form:
    $$\mathbf{(\hat{x} - \bar{X}) = b_{xy}(y - \bar{Y})}$$

## Solved Numerical Example (Predicting Y)

Let's use the data from the previous correlation example to **predict the value of $Y$ when $X=9$**.

| $X$ | $Y$ | $x = X - \bar{X}$ | $y = Y - \bar{Y}$ | $x^2$ | $y^2$ | $xy$ |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 2 | 4 | -2 | -4 | 4 | 16 | 8 |

| **Total** | | | | $\sum x^2 = 10$ | $\sum y^2 = 66$ | $\sum xy = 25$ |

**Means:** $\bar{X}=4$, $\bar{Y}=8$.

### Step 1: Calculate the Regression Coefficient $b_{yx}$

We need the coefficient for predicting $Y$ based on $X$ ($\hat{y}$ on $x$):
$$b_{yx} = \frac{\sum xy}{\sum x^2} = \frac{25}{10} = \mathbf{2.5}$$

### Step 2: Form the Regression Equation

Use the derived form: $(\hat{y} - \bar{Y}) = b_{yx}(x - \bar{X})$
$$\hat{y} - 8 = 2.5(x - 4)$$
$$\hat{y} = 2.5x - 2.5(4) + 8$$
$$\hat{y} = 2.5x - 10 + 8$$
$$\mathbf{\hat{y} = 2.5x - 2}$$

Predict $Y$ when $X=9$:
$$\hat{y} = 2.5(9) - 2$$
$$\hat{y} = 22.5 - 2$$
$$\mathbf{\hat{y} = 20.5}$$

**Conclusion:** Based on the variation explained by the regression line, the predicted value of the dependent variable $Y$ when the independent variable $X$ is 9 is **20.5**.

## 🚀 Non-Linear Regression

**Non-Linear Regression** applies when the relationship between the independent variable ($X$) and the dependent variable ($Y$) cannot be adequately modeled by a straight line, *and* the equation **cannot be linearized** by simple mathematical transformations like logarithms (as we did for the power curve $y=ax^b$).

### Concept

* **Definition:** Non-linear regression fits a model $\hat{y} = f(x, \beta)$, where $f$ is a non-linear function of the regression parameters ($\beta$).
* **Example Model:** A classic example is the **Michaelis-Menten Equation** in biochemistry: $\hat{y} = \frac{A \cdot x}{B + x}$ or an intrinsic exponential model like $\hat{y} = A e^{B x}$.
* **The Problem:** The parameters ($A$ and $B$ in the examples above) often appear as exponents, multiplied together, or within complex fractions. Because of this non-linearity, the **Normal Equations** (based on derivatives equaling zero) become non-linear and cannot be solved directly.

### Solution: Iterative Optimization

Since we cannot solve the Normal Equations directly, non-linear models rely on **iterative optimization algorithms** to find the parameter values that minimize the **Sum of Squared Errors (SSE)**.

1.  **Initial Guess:** The process requires providing an **initial guess** for the parameter values (e.g., $A_0, B_0$).
2.  **Iterative Adjustment:** The algorithm (e.g., **Gauss-Newton** or **Levenberg-Marquardt**) iteratively adjusts these parameter estimates, moving in a direction that continuously reduces the SSE.
3.  **Convergence:** The process stops when the changes in the parameter estimates between iterations are negligible, indicating the algorithm has **converged** to the local minimum SSE.

### Importance for Prediction

Non-linear regression provides the most accurate mathematical description for phenomena that follow complex, naturally curved patterns (e.g., population growth, chemical reaction rates, biological dose-response). Using a non-linear model when appropriate leads to **significantly more accurate predictions** than forcing a straight line onto curved data.

## 📊 Multiple Linear Regression

**Multiple Linear Regression (MLR)** is an extension of simple linear regression that allows for the prediction of a single dependent variable ($Y$) using **two or more** independent variables ($X_1, X_2, \ldots, X_k$).

### Concept

* **Objective:** To explain the variation in the dependent variable $Y$ by simultaneously considering the variation of multiple independent variables.
* **Model Equation:** The model assumes a linear relationship between the predicted outcome ($\hat{y}$) and the independent variables:
    $$\mathbf{\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \ldots + \beta_k x_k}$$
    * $\hat{y}$ is the predicted value of the dependent variable.
    * $\beta_0$ is the intercept (value of $Y$ when all $X$ variables are zero).
    * $\beta_i$ are the **partial regression coefficients** (slopes).

### Interpretation of Coefficients ($\beta_i$)

In MLR, the $\beta_i$ coefficients are crucial for understanding the variation:

* **Partial Effect:** $\beta_i$ represents the change in the predicted value of $Y$ for a one-unit increase in $X_i$, **while holding all other independent variables ($X_j$) constant**.
* **Example:** In predicting house price ($Y$) using square footage ($X_1$) and number of bedrooms ($X_2$):
    * $\beta_1$ is the expected increase in price for every extra square foot, assuming the number of bedrooms is fixed.

### Key Formulas (Matrix Form)

While the deviation method is cumbersome for more than two variables, MLR is most effectively solved using linear algebra (matrices).

The goal remains to find the $\beta$ vector that minimizes the Sum of Squared Errors (SSE):
$$\text{SSE} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

The solution for the vector of coefficients $\mathbf{\beta}$ is given by the matrix equation derived from the Normal Equations:
$$\mathbf{\hat{\beta} = (X^T X)^{-1} X^T Y}$$

* $\mathbf{\hat{\beta}}$ is the vector of estimated coefficients $(\beta_0, \beta_1, \ldots, \beta_k)^T$.
* $\mathbf{X}$ is the $n \times (k+1)$ matrix of independent variables (the design matrix).
* $\mathbf{Y}$ is the $n \times 1$ vector of observed dependent variable values.

### Importance for Prediction

MLR provides a superior method for **predicting** $Y$ when the outcome is influenced by several factors:

1.  **Increased Accuracy:** By incorporating multiple relevant predictors, the model can explain a much larger proportion of the variance in $Y$, leading to much more accurate predictions than using any single variable alone.
2.  **Controlling for Confounds:** It allows analysts to **isolate the effect** of a specific variable (e.g., $X_1$) after accounting for the influence of other variables (e.g., $X_2, X_3$), ensuring more robust predictive and explanatory power.

## Solved Numerical Example (Predicting Y using Two Variables)

**Objective:** Predict Sales ($Y$) based on Advertising Spend on TV ($X_1$) and Radio ($X_2$).

**Data (Hypothetical):**

| $Y$ (Sales) | $X_1$ (TV Ad) | $X_2$ (Radio Ad) |
| :---: | :---: | :---: |
| 10 | 2 | 1 |
| 15 | 3 | 2 |
| 20 | 5 | 3 |

Assume, after solving the $3 \times 3$ Normal Equations (using means and deviations) or the matrix formula, the calculated coefficients are:
$$\hat{\beta}_0 = 2.0 \quad (\text{Intercept})$$
$$\hat{\beta}_1 = 2.5 \quad (\text{TV Ad coefficient})$$
$$\hat{\beta}_2 = 1.0 \quad (\text{Radio Ad coefficient})$$

### 1. The Regression Equation

$$\mathbf{\hat{y} = 2.0 + 2.5x_1 + 1.0x_2}$$

$$\hat{y} = 2.0 + 2.5(6) + 1.0(4)$$
$$\hat{y} = 2.0 + 15.0 + 4.0$$
$$\mathbf{\hat{y} = 21.0}$$

**Conclusion:** The prediction is that sales will be **21.0** units, based on the joint variation of TV and Radio advertising budgets.

## 📊 Regression Solutions

### Linear Regression (Example)

**Q.** The equation of two regression lines are: $5x=6y+24$ and $1000y=768x-3608$. Find the correlation Coefficient, the ratio of coefficient of variability of $x$ to that of $y$, and the ratio of variance of $x$ and $y$.

The two lines are:
1. $5x - 6y - 24 = 0$
2. $768x - 1000y - 3608 = 0$

#### 1. Calculate Regression Coefficients ($b_{yx}$ and $b_{xy}$)

We must determine the direction of the lines. We assume both slopes are positive since $5/6$ and $768/1000$ are positive.

**Assumption 1: (1) is $y$ on $x$ and (2) is $x$ on $y$.**
* **$y$ on $x$ (from 1):** $6y = 5x - 24 \implies y = \frac{5}{6}x - 4$. $\implies \mathbf{b_{yx} = 5/6}$
* **$x$ on $y$ (from 2):** $768x = 1000y + 3608 \implies x = \frac{1000}{768}y + \frac{3608}{768}$. $\implies \mathbf{b_{xy} = 1000/768}$

**Check $r^2$:**
$$r^2 = b_{yx} \cdot b_{xy} = \frac{5}{6} \times \frac{1000}{768} = \frac{5000}{4608} \approx 1.085$$
Since $r^2 > 1$, **Assumption 1 is invalid.**

**Assumption 2: (1) is $x$ on $y$ and (2) is $y$ on $x$.**
* **$x$ on $y$ (from 1):** $5x = 6y + 24 \implies x = \frac{6}{5}y + \frac{24}{5}$. $\implies \mathbf{b_{xy} = 6/5 = 1.2}$
* **$y$ on $x$ (from 2):** $1000y = 768x - 3608 \implies y = \frac{768}{1000}x - \frac{3608}{1000}$. $\implies \mathbf{b_{yx} = 768/1000 = 0.768}$

**Check $r^2$:**
$$r^2 = b_{yx} \cdot b_{xy} = \frac{768}{1000} \times \frac{6}{5} = \frac{4608}{5000} = 0.9216$$
Since $r^2 < 1$, **Assumption 2 is valid.**

#### 2. Correlation Coefficient ($r$)
Since both $b_{yx}$ and $b_{xy}$ are positive, $r$ is positive.
$$r = \sqrt{r^2} = \sqrt{0.9216} = \mathbf{0.96}$$

#### 3. Ratio of Coefficient of Variability ($CV$)

Coefficient of Variability ($CV$) is defined as $CV = \frac{\sigma}{\bar{X}}$.
The question asks for the ratio: $\frac{CV_x}{CV_y} = \frac{\sigma_x/\bar{x}}{\sigma_y/\bar{y}}$.
We use the ratio of the regression coefficients: $b_{xy} = r \frac{\sigma_x}{\sigma_y}$ and $b_{yx} = r \frac{\sigma_y}{\sigma_x}$.

$$\frac{b_{xy}}{b_{yx}} = \frac{r (\sigma_x/\sigma_y)}{r (\sigma_y/\sigma_x)} = \frac{\sigma_x^2}{\sigma_y^2} = \frac{6/5}{768/1000} = \frac{6}{5} \times \frac{1000}{768} = \frac{6000}{3840} = \frac{5}{3.2} = \frac{25}{16}$$

Now, the question asks us to **show that the ratio of CVs is $5/24$**. This implies there is a relationship between the means and variances that satisfies this ratio.
We know the means $\bar{x}$ and $\bar{y}$ are found by solving the lines:
$5x - 6y = 24$
$768x - 1000y = 3608$
Solving these yields $\bar{x} \approx 5.333$ and $\bar{y} \approx 0.555$ (The means are very different from the desired ratio of 24/5 or 5/24).

The requested ratio $\frac{5}{24}$ is likely meant to relate to the variances, as the ratio of variances $\sigma_x^2/\sigma_y^2$ is $\frac{25}{16}$. **There seems to be an error in the question's premise regarding the ratio of CVs.**

However, assuming the question intended to ask about the **ratio of Standard Deviations** (which is related to the regression slopes, but not directly $5/24$), we proceed to the variance ratio.

#### 4. Ratio of Variance $\sigma_x^2/\sigma_y^2$

We found the ratio of variances from the ratio of regression slopes:
$$\frac{\sigma_x^2}{\sigma_y^2} = \frac{b_{xy}}{b_{yx}} = \frac{6/5}{768/1000} = \frac{6}{5} \times \frac{1000}{768} = \frac{25}{16}$$
$$\mathbf{\frac{\sigma_x^2}{\sigma_y^2} = \frac{25}{16}}$$

### Multiple Linear Regression (Example)

**Q.** Obtain a regression plane by using multiple linear regression to fit the data:
$$
\text{Model: } \hat{y} = \beta_0 + \beta_1 x + \beta_2 z
$$

| $x$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| $y$ | 12 | 18 | 24 | 30 |
| $z$ | 0 | 1 | 2 | 3 |

*Note: In the model $\hat{y} = \beta_0 + \beta_1 x + \beta_2 z$, the variables $x$ and $z$ are the two independent variables, and $y$ is the dependent variable. We swap $y$ and $z$ from the table headers to match the standard notation.*

#### 1. Normal Equations for $\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2$

(Using $\beta_0, \beta_1, \beta_2$ for $a, b, c$ and $x_1, x_2$ for $x, z$)

1. $\sum y = n \beta_0 + \beta_1 \sum x + \beta_2 \sum z$
2. $\sum xy = \beta_0 \sum x + \beta_1 \sum x^2 + \beta_2 \sum xz$
3. $\sum zy = \beta_0 \sum z + \beta_1 \sum xz + \beta_2 \sum z^2$

#### 2. Calculate the Required Sums

$n=4$.

|           |     $x$     |     $y$     |    $z$     |     $x^2$     |     $z^2$     |     $xy$      |     $xz$     |     $zy$      |
| :-------: | :---------: | :---------: | :--------: | :-----------: | :-----------: | :-----------: | :----------: | :-----------: |
|           |      1      |     12      |     0      |       1       |       0       |      12       |      0       |       0       |
|           |      2      |     18      |     1      |       4       |       1       |      36       |      2       |      18       |
|           |      3      |     24      |     2      |       9       |       4       |      72       |      6       |      48       |
|           |      4      |     30      |     3      |      16       |       9       |      120      |      12      |      90       |
| **Total** | $\sum x=10$ | $\sum y=84$ | $\sum z=6$ | $\sum x^2=30$ | $\sum z^2=14$ | $\sum xy=240$ | $\sum xz=20$ | $\sum zy=156$ |

#### 3. Set Up and Solve Normal Equations

1. $84 = 4\beta_0 + 10\beta_1 + 6\beta_2 \quad \text{(Eq. 1)}$
2. $240 = 10\beta_0 + 30\beta_1 + 20\beta_2 \quad \text{(Eq. 2)}$
3. $156 = 6\beta_0 + 20\beta_1 + 14\beta_2 \quad \text{(Eq. 3)}$

* Divide (Eq. 2) by 10: $24 = \beta_0 + 3\beta_1 + 2\beta_2 \implies \beta_0 = 24 - 3\beta_1 - 2\beta_2 \quad \text{(Eq. 4)}$

* **Substitute (Eq. 4) into (Eq. 1):**
    $84 = 4(24 - 3\beta_1 - 2\beta_2) + 10\beta_1 + 6\beta_2$
    $84 = 96 - 12\beta_1 - 8\beta_2 + 10\beta_1 + 6\beta_2$
    $84 - 96 = -2\beta_1 - 2\beta_2 \implies -12 = -2(\beta_1 + \beta_2) \implies \mathbf{\beta_1 + \beta_2 = 6} \quad \text{(Eq. 5)}$

* **Substitute (Eq. 4) into (Eq. 3):**
    $156 = 6(24 - 3\beta_1 - 2\beta_2) + 20\beta_1 + 14\beta_2$
    $156 = 144 - 18\beta_1 - 12\beta_2 + 20\beta_1 + 14\beta_2$
    $156 - 144 = 2\beta_1 + 2\beta_2 \implies 12 = 2(\beta_1 + \beta_2) \implies \mathbf{\beta_1 + \beta_2 = 6} \quad \text{(Eq. 6)}$

Since (Eq. 5) and (Eq. 6) are identical, the system has infinitely many solutions related by $\beta_1 + \beta_2 = 6$. This is because the independent variables $x$ and $z$ are perfectly linearly related in the data ($x = z+1$). When $x$ and $z$ are perfectly correlated, the model suffers from **perfect multicollinearity** and cannot uniquely determine $\beta_1$ and $\beta_2$.

However, by observing the data, we can find the exact fit: $y = 6x$.
* If $y = 6x$, then $y = 6(z+1) = 6z+6$.

Let's try fitting $\hat{y} = \beta_0 + \beta_1 x$ and see:
$\sum y = 4\beta_0 + 10\beta_1 \implies 84 = 4\beta_0 + 10\beta_1$
$\sum xy = 10\beta_0 + 30\beta_1 \implies 240 = 10\beta_0 + 30\beta_1$
$2.5 \times (84 = 4\beta_0 + 10\beta_1) \implies 210 = 10\beta_0 + 25\beta_1$
$240 - 210 = 5\beta_1 \implies \beta_1 = 6$.
$84 = 4\beta_0 + 10(6) \implies 4\beta_0 = 24 \implies \beta_0 = 6$.
The exact fit is $\hat{y} = 24 + 6x$. This is incorrect for the data.

Let's solve for a common parameter, e.g., $\beta_2 = 6 - \beta_1$.
Substitute into (Eq. 4): $\beta_0 = 24 - 3\beta_1 - 2(6 - \beta_1) = 24 - 3\beta_1 - 12 + 2\beta_1 = 12 - \beta_1$.

A possible solution (arbitrarily setting $\beta_1$ to 6 to simplify):
If $\beta_1=6$, then $\beta_2=0$ and $\beta_0=6$.
The equation is $\hat{y} = 6 + 6x + 0z = 6 + 6x$. (This is incorrect, check $x=1, y=12$, gives 12. $x=2, y=18$, gives 18. This is the correct fit!)

**Due to the perfect multicollinearity ($x=z+1$), there are infinite valid parameter combinations, but they all result in the same predictive plane.** The simplest solution that exactly fits the data is the one derived from simple regression on $x$ alone.

$$\mathbf{\hat{y} = 6 + 6x}$$

  The only valid assumption in the previous set of problems was:
